# AZEIR

Luxury wristwatch e-commerce site built with **Next.js 14**, the App Router, TypeScript, and **Tailwind CSS**.

## Scripts

```bash
npm run dev
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Home, collection, product, cart, and maison pages
- Sample catalog in `src/data/watches.ts`
- Client-side cart stored in `localStorage`
